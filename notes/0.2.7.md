# 0.2.7-extract: remove stale radius cache + native handoff during geometry transitions

Baseline: 43cade1b930b5817afa13a6f580361e8ccabd9d3 (0.2.6). No user logs, screenshots, video, pointers or device identifiers are committed.

Clean A/B evidence:
- The user disabled the full `dylv.liquidass` runtime and supplied the extracted package's `liquidasscc_4.log`. It contains no VolumeHUD / island-dump markers.
- StockOnly is real: 207 `[CCTRANS] stock-only-diagnostic` records and zero `custom-encoded`. The return still dark-flashed, excluding the custom Metal draw as a necessary condition.
- 235 `[CCVIEWTRANS]` rows: existing/wanted filter type always match; stock and glass alpha/model opacity stay 1; no logged layer animation keys; no style switch during the traced period. This points away from custom alpha math/type replacement as the StockOnly flash source.
- 116/235 rows have glass vs stock corner-radius mismatch. Common collapsed mismatch is 38.5 vs 21. The same glass pointers start with the native value and later return to 38.5.

Confirmed code defect:
- `LGInjectGlassIntoMaterialGroupType` saved the first provider result under `kLGRadiusKey`.
- `setFrame/setBounds` rerouted and could compute native 21/42, but `LGResyncGlassGeometry` later reapplied the stale associated value 38.5/75. This explains why the 0.2.6 source appeared to use native radius while the clean runtime trace did not.

Changes:
1. Delete `kLGRadiusKey`; resync reads current `mat.layer.cornerRadius` instead of a first-install snapshot.
2. If native material or sibling glass presentation geometry differs from its model geometry, temporarily show the stock material and hide glass. Re-evaluate every 80 ms until both settle, then restore normal glass ownership. This is limited to existing associated pairs; it adds no new matcher or renderer ABI.
3. Existing 0.2.6 native-radius policy, no global CALayer radius/animation override, stale filter-state reset, StockOnly/transition diagnostics and unchanged visual defaults remain.

Evidence boundary:
- The stock handoff is a reasoned fix for the clean StockOnly geometry mismatch; it is not yet device-validated.
- It does not modify custom shader alpha, output mapping thresholds, tint/blur/refraction defaults or renderer callback layout.
- Host tests and Apple build/static audit are gates; only device A/B can confirm the black flash and visual handoff.
