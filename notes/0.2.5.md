2. Keep the 0.2.4 MediaControlsMaterialView inner-strip exclusion. No album-art or control content is removed.
3. Construct rounded/clipped glass before insertion and use a disabled-action transaction for plugin geometry changes. Remove layout-order-dependent small-module radius caching. Do not force the stock slider fill's private mask radius.
4. Mark the CC overlay root. Allow a narrow set of fresh expanded-panel backgrounds within that scope even when no module ancestor or previous glass association exists. Outside CC remains excluded. No new daemon hook addresses/PAC rules.
5. Use the same window appearance for CC glass, avoiding forced MRU content style selecting a different glass tint/protection route.
6. Add only a near-uniform ControlCenter downscale route: each ratio 0.85–1, relative axis difference <=1%. Use floating-point normalized source coordinates; retain centered padding and all stock-first/device/usage/alias checks. This is a bounded experiment, not a proven CoreAnimation contract.
7. Original cyan/navy control-center icon generated by scripts/draw_icon.py, including 29/58/87px resources. No upstream icon reused.
